# MainAPIs · 1688 / 淘宝 / 天猫采集助手

当前版本：0.1.18。版本号以同目录 manifest.json 为准。

## 新设备安装（桌面版 Chrome / Edge）

1. 登录 https://ops.mainapis.com，进入「连接与配置」，下载采集助手 ZIP。
2. 解压到一个固定位置，保留 mainapis-1688-collector 文件夹，不要只打开 ZIP 内的文件。
3. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
4. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 manifest.json 的 mainapis-1688-collector 文件夹。
5. 将「MainAPIs · 1688 / 淘宝 / 天猫采集助手」固定到工具栏。

插件未上架浏览器扩展商店，下载 ZIP 后需手动解压、加载。各浏览器和各设备分别安装，不会随 OPS 登录自动安装。

## 使用

在同一浏览器登录 OPS 并保留标签页。打开 https://detail.1688.com/offer/数字.html 或 https://item.taobao.com/item.htm?id=数字，等待规格和图片加载，展开商品详情并滚动加载详情图片。点击插件「读取当前商品」，核对标题、主图、真实详情图、SKU 名称和配图，再导入 OPS 待整理采集箱。

0.1.9 保留独立规格维度（例如颜色、尺码）和每个 SKU 的对应值。若页面未提供维度名称，会显示“规格1、规格2”等，需在 OPS 核对命名；不从旧版已合并文本猜拆。

已存在的 OPS 商品可以导出本次采集 JSON，在商品编辑页选择“导入重新采集的规格结构”，按来源与 SKU 编码补回维度，保留当前价格、成本、库存和配图。核对后保存并重新审核。

详情采集支持在真实商品详情容器内读取开放的 Shadow DOM。无法读取的跨域内容或未加载详情不会用主图／SKU 配图代替。不同商品页面仍须人工核对。参考成本需要确认采购档位；售价、库存需在 OPS 完善，再审核发布。

## 更新

从 OPS 下载新版，解压并用新文件替换原插件目录中的内容。在扩展管理页点击本插件「重新加载」，再刷新商品页。已解压安装不自动更新。

## 权限和诊断

只在用户点击时读取当前商品页，不读取 Cookie，不要求填写平台账号密码。仅允许连接 ops.mainapis.com，导入结果归属于当前登录的个人或团队工作空间。

「页面结构诊断」导出当前商品的结构路径、字段名、DOM 类名等辅助信息；不导出 Cookie、账号或商品字段值。采集不完整时可使用诊断定位页面布局差异。

## 淘宝支持范围（0.1.12）

读取浏览器已打开且已加载的淘宝桌面商品详情页。先完成平台正常登录，展开规格和详情、滚动加载图片后采集。保留标题、主图、真实详情图、可识别的规格维度/规格图及参数；售价和库存置零，平台显示价格仅作为待核对参考成本。不能读取完整规格时返回空SKU并提示，不伪造单规格商品。

当前支持标准 item.taobao.com/item.htm?id=数字 链接。短链接请先在浏览器打开到商品页，不直接支持搜索列表或淘宝App页面。不读取Cookie或登录凭据，不执行网页脚本字符串、不调用隐蔽接口或绕过验证。详情如果未加载或位于不可读取的跨域框架，会明确提示缺失；可使用页面结构诊断（不包含字段值）协助适配。

淘宝商品可进入OPS编辑、SKU补图、详情/参数补充、同款整理和现有商城发布流程。具体淘宝页面有多种版本，需以真实商品页面采集结果核对。

## 天猫支持（0.1.13）

新增 https://detail.tmall.com/item.htm?id=数字 标准天猫桌面商品页。与淘宝使用同一读取器，保留独立的天猫来源身份；同数字ID的淘宝与天猫链接不会被当成同一商品。支持可读取的标题、图片、规格及参数，沿用售价和库存置零及不完整SKU拦截。短链接请先正常打开到标准商品页。不包含国际天猫或其他域名的自动跳转。需通过实际商品页面核对加载结果。

0.1.14（Safari资源0.1.17）：修复草稿缓存配额不足时中断采集的问题，优先独立缓存并提供保存失败后的直接导入/下载路径。

## 导入目标与费用

点击“查看导入目标与费用”，核对当前团队或个人空间和点数，再点击确认导入。此时才写入OPS；预览页面商品本身不扣点。插件不读取或保存OPS的Cookie、Token、CSRF或余额凭据，只在已登录OPS标签页内发起同源请求。

提交前重新核对价格和工作空间，变化时停止并要求重新查看费用；当前空间已有同来源商品时提示已存在，不覆盖、不再次收费。网络异常时先到OPS按来源查找，再保留原来源重试。OPS收费开关目前关闭，界面显示本次不扣点数。

需要OPS >=0.20.1；旧服务无法提供费用确认时停止导入，不绕过确认继续写入。插件只支持单件导入，下载JSON备用仍然可用。


0.1.16支持多个明确详情容器及更多懒加载属性。若详情仅1张，请先展开详情、滚动加载后重新读取；仍缺失时下载页面结构诊断用于核对，不代表单张一定错误。


0.1.17整理插件界面：读取、核对、确认导入三步，预览数量集中展示，规格参数和JSON默认折叠，异常诊断位于“更多工具”。导入仍需确认目标空间和费用。
