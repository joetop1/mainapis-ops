# MainAPIs · 1688 采集助手

当前版本：0.1.9。版本号以同目录 manifest.json 为准。

## 新设备安装（桌面版 Chrome / Edge）

1. 登录 https://ops.mainapis.com，进入「连接与配置」，下载采集助手 ZIP。
2. 解压到一个固定位置，保留 mainapis-1688-collector 文件夹，不要只打开 ZIP 内的文件。
3. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
4. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 manifest.json 的 mainapis-1688-collector 文件夹。
5. 将「MainAPIs · 1688 采集助手」固定到工具栏。

插件未上架浏览器扩展商店，下载 ZIP 后需手动解压、加载。各浏览器和各设备分别安装，不会随 OPS 登录自动安装。

## 使用

在同一浏览器登录 OPS 并保留标签页。打开 https://detail.1688.com/offer/数字.html，等待规格和图片加载，展开商品详情并滚动加载详情图片。点击插件「读取当前商品」，核对标题、主图、真实详情图、SKU 名称和配图，再导入 OPS 待整理采集箱。

0.1.9 保留独立规格维度（例如颜色、尺码）和每个 SKU 的对应值。若页面未提供维度名称，会显示“规格1、规格2”等，需在 OPS 核对命名；不从旧版已合并文本猜拆。

已存在的 OPS 商品可以导出本次采集 JSON，在商品编辑页选择“导入重新采集的规格结构”，按来源与 SKU 编码补回维度，保留当前价格、成本、库存和配图。核对后保存并重新审核。

详情采集支持在真实商品详情容器内读取开放的 Shadow DOM。无法读取的跨域内容或未加载详情不会用主图／SKU 配图代替。不同商品页面仍须人工核对。参考成本需要确认采购档位；售价、库存需在 OPS 完善，再审核发布。

## 更新

从 OPS 下载新版，解压并用新文件替换原插件目录中的内容。在扩展管理页点击本插件「重新加载」，再刷新 1688 商品页。已解压安装不自动更新。

## 权限和诊断

只在用户点击时读取当前商品页，不读取 Cookie，不要求填写 1688 密码。仅允许连接 ops.mainapis.com，导入结果归属于当前登录的个人或团队工作空间。

「页面结构诊断」导出当前商品的结构路径、字段名、DOM 类名等辅助信息；不导出 Cookie、账号或商品字段值。采集不完整时可使用诊断定位页面布局差异。
