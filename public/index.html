切换商城后需重新选择分类和品牌；既有发布记录不会改变。

商品标签暂按商城已有 ID 填写；不填写则留空。虚拟销量仅作展示，真实销量由订单累计。这些字段用于新建商品，不会自动更新已发布商品。

应用会更新下方全部规格的售价；点击「保存商品」后才会保存。

覆盖下方全部规格的库存，点击「保存商品」后生效。请填写可售库存；Tigshop 要求商品总库存大于 0。

导入商品资料

支持 JSON，或粘贴 1688 官方采购助手导出的表格（包含表头）。也可上传 UTF-8 CSV/TSV 文件。每次最多 100 件，重复来源会跳过。表格未提供 SKU，导入后需补充规格、成本、售价和库存。



创建发布任务
发布方式：下架入库。任务交给 n8n 执行，商城商品 ID 回传后才记为成功。
