新设备安装步骤
  1. 点击“下载插件 ZIP”，解压到一个固定文件夹，保留该文件夹。
  2. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
  3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
  4. 选择解压后的 mainapis-1688-collector 文件夹，里面应有 manifest.json。
  5. 将“MainAPIs · 1688 采集助手”固定到工具栏。在同一浏览器登录 OPS，再打开 1688 商品页，点击插件采集。

ZIP 下载后需要手动解压并加载。当前通过本页分发，尚未上架浏览器扩展商店。

已有插件如何更新

下载新版 ZIP，解压后用新文件替换原插件文件夹中的内容；到扩展管理页点击本插件的“重新加载”，再刷新 1688 商品页。

已解压安装的插件不会自动更新。切换到其他浏览器或新设备时，需要重新安装。

使用上方保存的商城AppID/AppSecret读取资料，需要订单列表、订单详情及售后列表只读权限。退款从售后列表核对申请金额，不调用异常的售后详情接口。仅接收配置后触发的原生事件，不自动补发历史事件。

商城原生通知转接配置（保存后复制）

商城后台 → 通知设置 → ID 19「下单给客服发消息」和 ID 18「申请退款给客服发消息」→ 设置。分别把企业微信地址、消息模板替换为下列对应值，并开启企业微信开关。模板必须完整复制，{order_id}保留不动。原来直发群的这两项改由OPS转发，避免双份消息。

接收地址含密钥，请勿截图分享。入口先持久保存接收记录，再异步读取资料；读取失败自动重试，最终失败可手动重试。退款只提醒近24小时仍待处理的申请，每次最多核对20页售后。商城原生任务不检查发送回执，未抵达OPS的事件不能保证自动补发；请通过真实付款、退款各测试一次。不要向此地址发送真实企业微信群Webhook。
