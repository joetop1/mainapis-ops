# OPS共享图片存储（0.8.3）

由OPS统一上传到阿里云OSS已有Bucket；无需安装商城扩展，不使用商城后台的存储密钥。Bucket需要管理员自行在阿里云开通，OPS不自动购买或创建云资源。

## 配置

系统管理员打开「系统设置 → 共享图片存储」。团队管理员不自动拥有全站存储管理权限。若全站有多个允许登录账号，按现有系统设置规则配置 `SYSTEM_ADMIN_SUBJECTS`（Casdoor准确sub）。

1. 创建专用阿里云OSS Bucket，选定地域，例如 `cn-hangzhou`（不含`oss-`）。
2. 使用OSS公网HTTPS地址或绑定的图片域名作为「公开图片域名」，不含路径。示例 `https://my-bucket.oss-cn-hangzhou.aliyuncs.com` 或 `https://images.example.com`。域名必须实际指向该Bucket的对象根目录；自定义域名须在OSS绑定并配置HTTPS。
3. 配置公开读取商品图片。OPS会以匿名GET读取新图片并逐字节校验；私有桶的临时签名URL不适合长期商品详情，当前不支持。若设置Referer防盗链，需要允许无Referer读取，并包含商城的实际前后台域名，否则OPS或商城服务器读取可能失败。
4. 创建专用RAM用户，AccessKey只授予此桶 `ops/` 目录的 `oss:PutObject`，不要使用主账号密钥。示例策略（替换 `YOUR_BUCKET`）：

```json
{"Version":"1","Statement":[{"Effect":"Allow","Action":["oss:PutObject"],"Resource":["acs:oss:*:*:YOUR_BUCKET/ops/*"]}]}
```

5. 填入AccessKey ID和Secret，允许列表每行填写一个商城完整HTTPS域名，例如 `https://shop.example.com`。必须与OPS保存的商城地址完全一致，`www`与不带`www`是两个地址，不支持通配符。
6. 点击「测试上传与读取」：写一张小PNG到 `ops/probes/` 并校验公开读取，测试不保存配置。通过后启用并点击「保存图片存储」。密钥使用现有 `connections.key` 加密存储，页面不返回原密钥；留空保留。

允许列表控制商城是否可申请OPS转存，并不是公开图片的访问控制。若需要防盗链，在OSS/CDN另行配置。勿把公开商品图片当成私密资料。

## 发布

在「创建发布任务」中，每个商城下有「转存图片到OPS存储」选项，每次打开默认不勾选。未启用存储、未授权域名或缺少分类的商城不能开启。仅选择的商城任务转存；不勾选仍走原发布流程。

处理主图、详情图和SKU配图，去重后依次下载、上传、读回校验，全部成功才替换该任务快照并调用商城创建。采集箱商品资料和SKU来源不会改变。未配置SKU配图继续由原发布器使用主图回退。

对象路径：`ops/<团队或个人哈希>/<商城哈希>/<任务ID>/<图片内容SHA256>.<扩展名>`。不同商城隔离目录；同任务重试使用相同内容键，避免多次产生不同名称。每张完成转存的源URL/目标URL保存在任务转存表；未完成时任务快照仍保留全部原图。

转存失败显示「图片转存未完成，未调用商城创建」，到任务列表点击「重发未领取任务」重试同一任务，不要另建任务。重试复用已经完成的文件。重启后未完成任务需要手动重试；不会自动创建商品。存储目标Bucket/地域/图片域名或商城域名变更后不能把原任务混转到新目标，需恢复原目标后重试。

## 限制与运维

- 仅阿里云OSS公网常规Endpoint；使用V4签名，不支持S3/COS、STS临时凭据、内网Endpoint和任意自定义上传服务器。
- 图片源必须为公网HTTPS；每跳重定向验证域名，DNS固定至公网IPv4，不向下载源发送云密钥。最多3次重定向。
- 每张最大10MB、单任务最多300个不同URL、累计最多200MB，支持PNG/JPEG/WebP/GIF文件头，不接受SVG/HTML。未调用解码器转换或压缩图片；文件头校验不保证图片视觉质量，仍需人工核对。
- 同时最多2个转存任务，其他排队。源站防盗链、超时或上传/读回失败均会阻止商城创建。
- 保存Bucket不会测试云权限；建议先点测试。无真实凭据的自动测试使用模拟网络，不代表真实桶已接通。
- 存储费和上传后访问流量由桶所有者承担，OPS本机只短暂占用内存，图片不存本地数据盘。
- 测试或中断可能留下未引用的对象，不自动删除。可为 `ops/probes/` 设置短期生命周期；切勿为整个 `ops/` 设置自动到期，因为商城仍可能引用这些图片。
- 备份整个OPS持久化数据目录（数据库和 `connections.key`）。历史商城图片依赖该Bucket和域名，应长期保留。

## 图片地址长度兼容（0.9.5）

新上传路径统一为 `ops/<空间SHA256前16位>/<图片完整SHA256>.<格式>`，不再把批次、任务和商城ID拼入URL。同空间相同内容共用对象，不同空间隔离目录。上传前要求完整图片URL不超过128字符，图片域名过长时提示更换短域名。

商品编辑页的“修复图片地址长度”会读取当前空间已有的OPS长地址，重新上传为短对象并验证图片内容；原对象保留，不自动删除。更改仅写入编辑表单，需要保存商品后生效。只支持当前存储域名下本空间的图片，不提供任意URL代理。

CRMEB创建前检查主图256字符、SKU图片128字符上限，SKU没配图时也检查作为回退的首图。选择发布时转存的任务会先转存再校验；已领取创建的任务不改写快照、不自动重建。
