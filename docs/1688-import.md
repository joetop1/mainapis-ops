# 1688 官方采购助手表格导入

升级 OPS 后，打开「商品采集箱 → 导入商品资料」，把官方助手导出的表格从 Excel **连同表头复制**到输入框，也可上传 UTF-8 CSV/TSV 文件。每批最多 100 件，继续兼容原 JSON 格式。二进制 `.xlsx` 文件暂不支持；请复制单元格或另存为 UTF-8 CSV。

支持样例列：序号、商品标题、宝贝ID、宝贝链接、图片地址、价格、代发价、销量、评论数、月成交笔数、月代销、发货时间、上架时间、类目、标签。列顺序可变化，必须有「商品标题」以及「宝贝链接」或「宝贝ID」。链接必须是 HTTPS 1688 商品详情链接；跟踪参数自动去除，链接和 ID 同时出现时必须匹配。重复来源跳过，不覆盖现有商品。

- 标题、来源链接、单张图片写入待整理商品。样例图片为 310×310 缩略图，原样保留，不擅自改链接冒充高清图。
- 价格、代发价、来源类目、来源标签、供应商销量、发货时间、上架时间只保存在 `sourcing` 采购参考资料。商品编辑页展示主要参考信息，编辑保存后保留。
- 不把供应商销量当商城销量；来源标签和类目不自动映射到商城 ID。
- 表格没有完整 SKU、库存、详情、套图：不生成虚假单规格，不猜售价。导入后需要补充目标分类、规格、采购成本、售价和库存，再审核发布。
- 导入遵循既有账号隔离、CSRF、去重和审核规则，不新增 API 密钥，也不改动 n8n。只更新 OPS 容器即可。

本地测试使用运营者提供的 755369163302 商品样例，覆盖跟踪参数、价格参考、无 SKU 阻止审核、CSV 引号/换行、空列、列数错误、ID 不匹配、批量上限、重复来源及 HTTP 导入链路。尚未进行线上浏览器验收。
