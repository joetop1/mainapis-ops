# ShopXO 6.9.2 接入（OPS 0.6.0 / 独立扩展 0.1.0）

用户确认商城 xiaolanyoupin.wang，后台入口为独立改名入口，软件6.9.2 / PHP8.0.31 / MySQL8.0.45 / PHP-FPM。直接只读访问后台返回HTTP468，未尝试登录、绕过网关或修改服务器。

## 审核依据

ShopXO官方仓库 https://github.com/gongfuxiang/shopxo 的 v6.9.2 分支，固定提交 9a0a99fd54be5decc4c8587a5d07bbec7b80d399。核心文件通过 GitHub Contents API获取并核对Git blob SHA/size，预检指纹为CRLF转换LF后的SHA256。实际安装包如有业务补丁或其他版本，预检拒绝并报告source_file；不能跳过。

核对的服务包括 GoodsSave、规格解析/插入、相册与手机详情、ResourcesService附件路径转换、GoodsParamsService必填模板、WarehouseGoodsAdd/InventoryData/InventorySave。库存由仓库服务同步到商品/规格，不能单写商品inventory。主图/规格图字段最多255字符，适配器使用250字符保守限制，过长链接需转存。维度值图片是原生展示字段，无法完整表达的逐组合图片在提交前拦截。

## 实现

- 系统类型ShopXO独立，按具体商城连接保存域名、独立应用ID/密钥与仓库。
- 加密凭据沿用连接存储；测试不保存，保存须选择实际返回仓库。
- HMAC-SHA256对base64原始UTF8请求签名，附时间戳和随机nonce。固定POST入口不跟随重定向，OPS使用固定公网DNS传输器。
- 商城独立入口只提供capabilities、lookup、create、detail；不使用管理员密码、不开放原始SQL或任意文件写入接口。
- 商城新增自有文件、回执和nonce两张表，不覆盖核心文件、不改原表结构。
- 创建前先保留持久回执，再调用原生商品/仓库服务。任何不确定结果都保留领取锁，不自动重新创建。明确商品ID核对可将相同唯一任务货号的未完成回执绑定到该商品；不改商品数据。
- 读回核对原生货号、标题、下架状态、分类品牌、仓库、主图/封面、电脑HTML和手机详情图、规格名/值/编码/售价、原生库存与仓库库存、原生维度值图片。
- 采购参考成本存于原生规格JSON扩展字段extends.mainapis.cost并核对，不假设商城有原生成本列。运费沿用商城，当前金额按人民币写入；其他基础币种尚未适配。虚拟销量忽略；CRMEB标签不映射。文本参数保存在富文本里，原生分类必填字段/参数模板不能表达时停止，不造数据。
- 仅普通平台商品，不支持多商户店铺或门店独立库存、虚拟商品。扩展当前仅首次安装及停用，没有强制覆盖更新或自动卸载。

## 分发与操作

部署OPS后，连接与配置页面ShopXO卡片提供完整tar.gz及安装说明，服务在Docker镜像中直接从固定白名单源码生成压缩包，不依赖开发机dist。新增连接与默认ShopXO连接都可使用。

完整步骤见 integrations/shopxo/bridge/INSTALL.md。先上传到商城/tmp解压，再用商城对应PHP CLI运行 --check，只有ok:true后运行--install。安装后在服务器本机运行--credentials，将密钥直接填到OPS，勿贴聊天。若Web根目录是项目/public，需在命令尾部显式传入该目录，入口安装在Web根目录，核心配置仍放项目根目录自有目录。配置文件属主与runtime一致，须由网站用户读取。

HTTP468为已观察到的网关响应；实际签名测试如果受拦截，由管理员核对独立路径网关规则，不关闭全站防护。
