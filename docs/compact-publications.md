# OPS 0.5.2 紧凑发布记录

采集箱不再逐个堆叠商城徽章及商品ID。每件商品默认显示一行“已发布 3/4 · 查看”，历史成功版本计入已发布；存在待核对、失败或执行中任务时显示额外的短提示。

点击查看打开详情对话框，列出商城名称、固定系统、状态、发布版本及商城商品ID，标记历史版本。原有未配置连接过滤与历史记录保留规则不变。使用按钮而非仅悬浮显示，支持触屏与键盘。

153项现有测试通过。jsdom检查验证3/4摘要、列表不展开ID、对话框4个商城及ID/未发布状态保留、关闭及待核对提示；分页和回顶交互也通过。未完成真实浏览器视觉截图验证。
