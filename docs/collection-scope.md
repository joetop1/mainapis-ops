# 采集箱按采集人查看（OPS 0.6.9）

团队仍共用商品，页面每10秒刷新。采集箱默认请求 collection_scope=mine，服务端按当前登录sub与团队owner共同筛选，筛选后才应用1000件读取上限。选择「团队全部」查看团队共享商品；这是视图筛选，不改变团队原有编辑、审核、发布权限。切换范围及自动刷新采用请求序号避免慢响应覆盖新视图。

新增独立 product_collectors 表记录商品原采集人sub与当时显示名称，不改products列布局。创建和导入以服务端登录身份写入，忽略客户端伪造归属。编辑和审核不改变采集人。个人转团队时稳定商品ID保留采集人。

启动时回填：个人空间owner；团队product.create事件中的actor；历史个人product.create审计owner（用于个人转团队前记录）。无可靠记录的商品不猜测归属，在团队全部中显示「历史采集人未知」。回填可重复，已记录归属不覆盖。

仅更新OPS，无需更新采集插件或商城。原来源链接去重范围仍是团队，其他人采集过的同一来源不会变成重复商品。API未指定scope保留all兼容既有调用方，前端明确传mine作为默认。测试168项通过，包括两成员真实handler模拟、导入身份、防客户端伪造、个人转团队及未知历史记录。
