# 批量分类与品牌（OPS 0.9.3）

## 采集箱

勾选商品（可跨页，最多100件），点击「批量设置分类 / 品牌」。货盘商品也可以勾选；1688来源合并仍限制最多20件，且不支持货盘商品参与合并。

选择目标商城后，从该商城真实可见分类、品牌列表中选择。分类或品牌留空表示不修改该字段，不用于清空。默认「仅填空缺」按分类、品牌分别判断；「覆盖」只覆盖选择的字段及目标商城映射。其他商城映射、标签、门店适用范围、来源资料、价格库存与图片均保留。

成功修改的商品版本加1，回到待整理，需要重新审核。没有实际改变的商品不增加版本。不会修改已冻结的发布任务快照或商城已创建商品。按商品返回结果，版本冲突或归属错误不会覆盖当前资料，也不回滚其他成功项。

## 货盘预览

先勾选需要设置的商品，再点击「批量设置已勾选商品的分类 / 品牌」。可以对不同商城重复设置。预览中的映射摘要即时显示，SKU编辑内容保留；点击正式导入后才写入商品。尚未填写库存也可以先设置分类品牌。

这一步的映射暂存在当前网页；刷新页面前请完成导入。已经开始导入的批次不能改变原计划。重复来源商品仍沿用跳过逻辑，不用货盘设置自动覆盖已有商品；如需调整已有商品，使用采集箱批量设置。

## 验证

服务端再次核对商城归属及真实分类、品牌，忽略客户端伪造的分类名称，使用商城实际路径。供应商映射随导入计划冻结，后续原任务重试使用相同设置。仅有品牌而没有分类的商品仍需补全分类后才能审核发布。

不需要更新浏览器采集插件、商城扩展或n8n。
