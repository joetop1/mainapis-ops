# OPS 0.4.7 商城名称

商城系统固定，由渠道 id 决定。商城名称由团队管理员在对应连接配置内独立保存，1–50 字。一个团队每种系统仍只有一个渠道。本次不改变 CRMEB/Tigshop 固定接口地址或认证方式。

名称保存在独立加密 profiles 配置中，团队创建时随个人配置迁移，不与密钥表单互相覆盖。采集箱发布徽章、发布任务列表、目标选择及编辑商品的商城选项使用自定义名称；连接卡片额外保留固定系统标签。历史任务仍按稳定渠道 ID 归属，改名后显示该渠道当前名称，不创建新商城、不移动商品。

验证：143 项测试通过，包含系统字段不可通过改名覆盖、名称校验、改名不改变连接就绪状态、团队迁移、读取隔离及编辑员不可改名。部署 OPS 后刷新网页，连接配置中填写名称并保存。不需更新商城扩展或浏览器插件。
