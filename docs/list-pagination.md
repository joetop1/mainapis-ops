# OPS 0.5.1 列表与待配置商城显示

配置统计改为“X 个已配置 · Y 个待配置”。新增商城时只保存连接身份与名称，未保存有效凭据的连接仍为待配置；仅测试连接不会变为已配置。

采集箱发布徽章仅显示已配置商城，或该商品在其中已有任务的商城。即使连接后来失去配置，已有任务及商品ID仍可见；未配置且从未发布的新增商城不显示徽章。

商品列表对已加载的最多1000条商品按20/50/100条分页，搜索/筛选重置第一页。发布任务 GET /api/jobs 支持真正的服务端分页，按创建时间与任务ID稳定排序、工作空间隔离，包含商品标题，不受 /api/state 最近300条任务上限影响。列表展示期间自动刷新保留页码，越界自动回到最后有效页。

滚动超过350px显示回到顶部按钮；点击平滑返回，尊重减少动态效果设置。

153项测试通过，含草稿连接不继承凭据、仅测试不保存、历史徽章保留、345条任务跨页查询及工作空间隔离。jsdom完整应用检查通过商品/任务翻页、末页、搜索重置和回顶按钮显示/点击；未完成真实浏览器视觉截图检查。

仅更新 OPS，无数据库结构变更，不需要更新商城扩展或浏览器插件。
