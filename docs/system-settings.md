# 系统基本信息管理

OPS 0.8.2。左侧「系统设置」支持系统名称、品牌名称、浏览器标签页标题、站点Icon、侧栏Logo、登录主标题和说明。
这些是整个部署实例的公开品牌信息，不属于单个商城或团队；修改后影响全部用户。

## 管理权限

系统管理员由服务器环境变量指定，使用 Casdoor 精确的用户 sub，不是显示名称：

```dotenv
SYSTEM_ADMIN_SUBJECTS=你的Casdoor用户sub
```

多个系统管理员用英文逗号分隔。这些账号还需要原有的登录访问权限。
未设置此变量时，若 ALLOWED_SUBJECTS 只有一个账号，该账号兼容为系统管理员；
若白名单有多个账号则不会猜测管理员，需明确设置 SYSTEM_ADMIN_SUBJECTS。
显式设置空值表示没有系统管理员。普通团队管理员、创建新团队的个人用户不会自动获得此权限。
后台API逐次鉴权并检查账号停用状态，POST还要求原有Origin和CSRF令牌。演示模式不修改全站信息。

现有部署只有一个原始白名单账号时，更新后即可看到入口。
如果入口不出现，在服务器 .env 填写 SYSTEM_ADMIN_SUBJECTS 后重新创建OPS容器：

```bash
cd /www/wwwroot/mainapis-ops
docker compose up -d --build
```

## 修改与上传

登录后进入「系统设置」，填写名称、品牌、标签页标题及登录文案。
Icon用于浏览器标签；Logo用于页面左侧品牌区。文件直接从本机上传，不填写第三方图片URL。
Icon建议方形256×256透明PNG；另支持ICO、JPEG、WebP。Logo支持PNG、JPEG、WebP。
每张最多1MB，客户端检查能否作为图片读取及宽高不超过4096；服务端按真实文件头识别格式、检查大小及PNG尺寸、ICO边界。
不接受用户SVG/HTML。默认M图标为系统内置SVG，与上传校验分开。
图片预览只在当前表单生效，点击保存才改变全站。未上传的新图片保留现状；恢复默认按钮同样在保存后生效。
上传读取期间暂停保存，避免只保存了文字却遗漏图片。

保存后当前页面标题、品牌和Logo立即更新；其他标签页刷新后生效。
服务器首屏HTML也使用已保存信息，未登录页同样展示正确名称和图标。
文案按纯文本展示并做HTML转义；不允许自定义HTML、JS或样式注入。
Icon地址包含内容摘要，每次更换会更新地址；图片响应不长期缓存，避免浏览器一直显示旧图。
若浏览器仍显示以前的图标，可刷新或关闭重开该标签页。

设置和图片保存在现有持久化SQLite数据库中，包含在原数据卷和数据库备份内，重建容器不会恢复默认。
保存包含设置版本检查，多个管理员同时修改时过期版本返回冲突，需要重新读取，不覆盖另一人的更新。
设置、图片和管理员审计在同一事务内保存；无效图片不会导致文字或旧图片被部分覆盖。
此功能不修改域名、Casdoor登录配置、商城连接或采集插件。

## 验证

自动测试覆盖系统管理员边界、团队管理员隔离、CSRF、匿名首屏及图标读取、HTML与替换符转义、
文件头/尺寸/ICO边界校验、无效上传回滚、图片默认恢复、数据库重开持久化，以及表单预览和保存生效。
浏览器视觉表现及真实上传仍需更新后在页面验收。
