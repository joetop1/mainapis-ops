# 独立商品详情图

采集器 0.1.6 起用 detail_images 保存真实详情区域的图片（最多100张），images 为主图，skus[].image 为规格图。不会把主图或SKU图当详情图。详情区尚未加载或跨源 iframe 无法读取时明确提示缺失，不绕过浏览器访问控制。

源站操作：重新加载扩展，刷新1688商品页，滚动到商品详情等待加载，点击读取当前商品（不要仅恢复旧预览）。预览分别显示主图、详情图、规格数量。OPS 编辑页提供独立详情图片地址输入，可检查或手工补充。

OPS 需要更新部署。Tigshop 后端直连自动使用新代码。CRMEB 的已发布 n8n 工作流包含旧代码，也需要更新：在「配置分类运费并转换字段」的 buildOfficialProduct 函数内找到原来的 `const description=...+images.map(...)` 整行，以 workflows/crmeb-detail-description-fragment.js 三行替换。仅替换此行，保留该节点末尾 config 中实际运费模板及其他配置，保存并 Publish。会员和多门店各自更新。

已经发布的商品不会自动更新，不能删除重建来修复详情；拿到真实详情图片后，可在商城后台编辑该商品的详情并保存。已有商品继续保留当前SKU、价格库存。
