# 商品编辑页本地图片上传（OPS 0.9.4）

商品编辑页新增「上传本地主图」「上传本地详情图」，每个SKU图片单元格也可选择本地图片。不需要先制作JSON，也不需要手动上传OSS再复制链接。

前提：已启用共享图片存储，当前个人/团队至少一个商城域名在允许列表中。上传沿用该桶及图片域名，不接受客户端传入上传目标或密钥。

- 支持PNG/JPEG/WebP/GIF，单张最大10MB。实际校验文件头，不依赖扩展名。
- 主图、详情图支持多选，按选择文件的列表顺序追加到现有图库；主图最多30张、详情图最多100张。
- SKU一次上传一张，替换该SKU的配图；可继续手工修改图片地址。
- 上传成功后仍需点击保存商品。上传期间暂停保存，仍可查看预览。上传失败时已成功加入的图片保留，错误明确显示，不继续后续文件。
- 关闭或切换编辑窗口后，旧上传结果不会加入另一件商品。上传到云端但未保存的对象可能保留，不自动删除。
- 目录为 `ops/<空间哈希>/local/<内容SHA256>.<格式>`。同空间相同内容使用相同地址，不同空间隔离。没有使用原始文件名作为对象路径。
- 上传操作和修改商品使用现有会话、CSRF及团队权限。编辑角色可上传；演示模式禁用。

已有「从1688采集JSON补充详情图」入口保留，仍仅适用于匹配来源的采集JSON，与本地上传分开。

部署无需更新商城、n8n或采集插件；如反向代理报413，需将OPS站点请求体限制调到至少15MB。
