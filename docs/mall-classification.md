# 商城商品只读整理清单（0.26.1）

本版遵循“不修改商城代码”的要求。只读取CRMEB会员商城商品，生成分类和商品标签对照清单，由运营人员在商城原生后台批量执行。不要再运行0.26.0提供的商城补丁或接口登记命令。

## 接口核实结论

已核对用户提供的CRMEB Pro 4.3源码：

- 对外 `/outapi/product/list`、`/outapi/product/:id` 可通过现有AppID/AppSecret只读访问。官方列表强制 `is_show=1`，不能把它当作全量商品列表。
- 对外 `productSave` 是整商品保存接口，会读取大量默认字段并处理SKU、库存、详情及业务事件，不能用来局部修改分类标签。
- 官方后台 `/product/batch_process` 支持分类（type=1）和商品标签（type=2）局部批量操作，但依赖管理员登录态、后台权限和商城任务队列，不能复用OPS的对外Token。OPS不会保存管理员密码或擅自复用后台Token。
- 官方后台标签批量设置是替换完整标签集合，追加/移除建议需要先算出每件商品的完整目标集合；不同目标集合不能混为一批。

## 使用流程

1. 更新OPS至0.26.1。无需修改商城文件、安装补丁或新增商城接口；OPS应用需已有商品列表及详情的官方读取权限。
2. 打开“商城商品整理”，选择小蓝优品对应的CRMEB会员商城连接，核对系统类型和域名。
3. 默认按名称分页读取上架商品。下架商品或明确目标商品可输入ID，每次最多20个，读取官方详情。按ID模式不分页。
4. 当前页可选择最多50件商品。勾选需要调整的目标分类；标签支持保留、追加、移除、替换建议，也可填写自定义建议标签。
5. 生成预览时重新读取商品详情，保存原分类ID、原商品标签ID及可读取的名称，展示完整目标分类和标签集合。原标签名称读不全时，追加/移除会拦截；保留/明确替换仍保留原ID并提示核对。
6. 下载CSV清单，按目标分类和完整目标标签集合分组，在商城后台商品列表勾选对应ID，分别使用“批量修改分类”和“批量设置商品标签”。先用1件验收，再扩大范围。
7. 商城原生批处理是异步队列，提示接收不等于完成。等待队列执行后在商城后台逐项核对，必要时按ID重新读取OPS清单。OPS不自动判定人工执行成功。

## 范围与限制

- 不请求任何商城业务写接口；远端唯一POST是官方access_token授权请求。分类整理模块不触发商品新增、保存、上下架或批量修改请求。
- 关闭0.26.0旧的同步、执行核对和自动回退路由，不启动分类写入Worker。已有分类整理旧表不删除，但旧版执行记录不再提供自动执行。原商品发布Worker正常保留。
- CSV是人工核对清单，不是商城官方商品导入模板，不能直接作为更新文件导入。
- 分类来自商城公开的可见分类，不保证包含后台隐藏分类。
- 标签选项是根据讨论整理的建议名称，并非商城标签字典或已经存在的标签。实际创建/选择标签和名称核对均在商城后台完成。功能性标签必须有相应商品资料支持。
- 本版不自动判断用途、不调用外部模型、不自动创建分类或标签。价格、库存、SKU、图片等不在整理写入范围，因为本版根本不写商城业务数据。
- 需要撤销时参考CSV中的原分类和原标签ID，在后台人工恢复；清单不是原子回滚方案，不能覆盖他人之后的修改。
- 清单按工作空间及商城隔离；编辑成员可读，审核员和管理员可保存建议清单。导出要求当前会话，文件禁止缓存，并对CSV公式开头做转义。
