# 供应商货盘导入（OPS 0.9.0）

入口：商品采集箱 → 供应商货盘。第一版针对这次收到的左右并排商品卡片式XLSX报价单；不是通用AI解析器。普通行列表、PDF、图片截图、ZIP及任意供应商版式尚不支持，遇到新格式先提供样本适配。

## 使用

1. 先配置并启用「系统设置 → 共享图片存储」，上传与匿名读取测试通过。当前空间至少一个商城的域名须在共享存储允许列表中，才允许使用共享桶导入图片。
2. 填写供应商名称，上传原始 `.xlsx`（最大100MB、每批最多100件）。同一供应商尽量保持名称一致，用于来源去重。
3. 预览商品及原表嵌入图片。批发价作为成本、零售价作为建议售价，可逐SKU调整。按原报价币种“元”处理，不做税额或汇率计算。
4. 对照条码填写规格与真实库存；库存始终留空待填。多个条码不自动猜款式对应关系，也不自动拆分商品标题中的斜杠。每个SKU需确认正售价、非负成本、非负整数库存。
5. 勾选“我已核对这件商品及SKU对应关系”，点击导入。可只选一部分明确的商品，暂时跳过不确定的商品。
6. 图片上传到共享OSS，读回验证成功后商品才作为草稿写入采集箱。缺图片仍可导入草稿，但不能通过审核。之后编辑商品，选择各商城真实分类品牌，审核后手动发布。

## 保存与边界

- 保存供应商、货盘文件名、批次ID、卡片位置、原条码、原分类提示和采购箱规，不把原表分类当成商城分类。
- 产品成分与产品参数写入产品属性；表格描述作为文字详情；嵌入图片作为主图。供应商营销文案仍需自行审核。
- SKU编码优先采用表内条码；无条码生成明确的 `SUP-` 内部编码，不虚构条码。尚未额外对接商城专用条码字段；原条码保存在来源记录及SKU编码中。
- 货盘商品使用内部 `supplier:` 来源标识，无需伪造1688链接。编辑时保留可信来源信息；暂不支持与1688商品进行来源合并。
- 同空间、同供应商、相同条码组（无条码时按标题）重复导入会跳过已有商品，不自动改价或覆盖资料。不同供应商分开保存。
- 每项结果持久保存；部分失败可以用原计划重试，成功项不重复创建。开始导入后冻结选择和SKU内容，修改计划需重新上传建立新预览。
- 进程重启不自动继续上传。再次打开货盘入口可读取浏览器记住的最近批次，点击导入重试；后台已有成功商品仍跳过。
- 预览24小时后清理，最多5份/空间。删除预览不会删除已导入商品或OSS对象。原始XLSX解析后删除，预览期仅保留提取的图片；供应商原文件请自行留存。
- 不执行宏、公式、远程图片或外部链接。仅支持PNG/JPEG/WebP/GIF嵌入图片，不支持WPS单元格图片、外链图片、SVG/EMF等。
- XLSX安全限制：3000个条目、解压总量300MB、单个条目20MB、单张图片10MB；解析120秒超时；同时最多2个货盘导入。

## 部署

Docker镜像新增Python3（标准库解析XLSX），无需pip第三方库。非Docker部署需安装Python3，或用 `PYTHON_BIN` 指定解释器。

```bash
cd /www/wwwroot/mainapis-ops
git pull --ff-only
docker compose up -d --build
```

若上传返回413，请把OPS站点反向代理的上传限制设为至少64MB；因JSON封装，实际请求会比原始XLSX更大。不需要改商城服务器或n8n。

实际样本只做本机只读解析验证，未提交供应商原文件、图片或价格。真实样本识别37个卡片和37张关联图片；不代表所有供应商格式均可识别。自动测试使用合成报价单和模拟OSS，不代表真实商品已导入或发布。

## SKU增减与窗口导航（0.9.2）

导入预览中每件商品可以新增或删除SKU（最少1行、最多50行），并编辑条码/SKU编码、规格、成本、售价和库存。空白或重复单元格导致的识别问题可以在提交前纠正，不再要求SKU数量与识别出的条码数量相同。

原表条码独立显示作为参考；删除一行不会按位置把其他行改绑到另一个条码。无条码的新行生成独立内部SKU编码。原条码及最终SKU编码均保存在来源记录中。增减SKU会自动取消该商品确认，需要重新核对勾选。开始导入后的原计划仍冻结，避免重试改变已成功商品。

货盘窗口向下滚动后显示“回到顶部”悬浮按钮，只滚动该窗口，不影响背景页面。

## 后台解析（0.13.1）

上传使用二进制文件，页面显示上传百分比；上传成功后批次持久入队，由独立Worker逐份解析。可关闭窗口，再次打开恢复最近批次，查看排队、解析、待确认或失败原因。浏览器上传期间请勿关闭窗口。解析失败不会写入商品；处理中断超过5分钟标为失败，可删除后重新上传。原有SKU增减、批量品牌分类和库存设置保留。

每份仍最多100件商品，单图10MB、单条目20MB等限制保留。100MB只提高原文件上限，不保证所有版式可识别。服务器反向代理须允许至少110m请求体，并为上传保留足够超时时间；上游代理若有更低的上传上限仍会拦截。该接口不执行公式或外部链接。

更新时运行整个Compose项目，确保worker在线；兼容单进程模式由网页服务后台调度。图片仍在确认导入时上传到OSS，后台解析不自动导入或发布。暂不提供解析百分比、分页预览或任意表格版式识别。
