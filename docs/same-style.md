# 货盘同款整理

先导入货盘到采集箱，再用已有采集助手采集对应1688商品。勾选1至19条同款货盘商品，点击“同款整理 · 补充采集资料”。可同时勾选一条采集商品，窗口会预选它；也可在窗口内选择已加载的采集商品。

1. 选择采集图文资料、分类品牌继承的货盘主商品、最终标题、规格维度及主图来源。
2. 为每个货盘SKU填写最终规格名称，选择对应采集规格。仅唯一且精确同名的规格预选；请人工核对。采集规格不能重复对应，不需要的采集SKU不会导入。
3. 点击“预览并检查”，确认数量及警告后生成新待整理商品。在编辑页检查图文、删除重复图片、排序或上传本地图片，保存后审核发布。

保留全部选中货盘SKU的编码（条码）、成本、售价和库存；这些数值不使用采集数据。详情图片、说明和产品参数来自采集资料；分类品牌映射来自指定的货盘商品，虚拟销量置零。未匹配SKU保留货盘图；已匹配SKU采用采集规格图，没有规格图时回退到采集主图。条码重复或最终规格名称重复会阻止生成，须先核对原始商品。

来源原记录、版本、历史发布与商城商品均不修改。新商品保留逐SKU来源和全部来源商品ID；已用于整理的来源在列表中默认收起，勾选“显示已用于同款整理的来源”可查看。生成操作可用同一请求重试，不会重复生成。已有商城发布任务会在预览中提示，新商品发布可能形成另一件商城商品。

当前仅选择已采集入箱的资料，不根据网址自动抓取淘宝/1688，不提供图片压缩包的自动识别。已有本地图片上传仍可在生成后的编辑页使用。
