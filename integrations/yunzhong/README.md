# 芸众官方 API 对接

本方案仅修改 OPS，使用商城已有的 https://asns.cc/outside/1/ 接口。不安装商城插件，不新增 PHP 文件，不更改路由、数据库或商城配置。

连接凭证在 OPS「连接与配置 → 芸众商城」输入并加密保存，不填进 n8n。分类模式由管理员按照商城现有设置明确选择；固定运费单位元，免运费填写0。测试连接只读取列表和分类，不创建商品。

当前支持两级分类、单维 SKU、逐 SKU 价格/成本/库存/配图、主图和图片详情，创建为下架商品。原生接口无法完整保存文字详情与产品参数，多维规格服务存在跨维度 ID 累积问题；这些商品在发送创建请求前拦截，不丢弃或合并数据。三级分类、品牌、标签及虚拟销量也不提交。

创建基础商品与 SKU 是两次请求，无法通过官方接口组成事务。OPS 使用任务领取锁防止重复创建；取得商品 ID 后立即保存，SKU 请求失败或结果不明时先到商城核对，不能直接重建。

官方读回不提供分类、完整主图组和详情内容，任务保持「待人工核对」，即使基础字段和 SKU 全部匹配也不标记成功。需要在商城后台人工核实。

本地自动化测试使用模拟官方响应，不代表真实商城已联调成功。当前按用户要求暂不部署 OPS；后续部署只更新 OPS Docker，商城和采集插件无需安装新文件。
